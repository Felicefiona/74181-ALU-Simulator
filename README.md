# 4-Bit ALU Simulator Using IC 74181

## About the Project
This project is a software-based simulator of a 4-bit Arithmetic Logic Unit (ALU), based on the function table and control inputs of IC 74181.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Accepts two 4-bit binary inputs.
- Supports arithmetic and logic modes.
- Allows function selection using four control bits.
- Displays the 4-bit result.
- Demonstrates selected ALU operations.

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.

## Project Note
This is an educational software simulation, not a physical implementation of IC 74181. Carry output calculation is not implemented in this version.
